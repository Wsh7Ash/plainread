# Changelog

## [1.0.0] - 2026-11-13

### Added

- Flesch Reading Ease, Flesch-Kincaid grade and a 0–100 style score.
- Long-sentence, passive-voice, hedge, repeated-opener and overused-word checks.
- Markdown stripping (fences, inline code, links, emphasis, HTML).
- Text and JSON reports, `--out`, `--max-sentence`, `--fail-under` gate.
- File and stdin input.
- pytest suite covering metrics, rendering and CLI exit codes.
